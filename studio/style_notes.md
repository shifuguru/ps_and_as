# Style notes

## Tone

- **Player copy:** Plain language, no dev jargon. Rules and UX first.
- **Studio copy:** Direct, operational — Mission Control is for directors and agents.

## Visual language

- Felt green table, gold accents, blur panels — see `src/styles/theme.ts`
- Turn state: bell highlight on active seat; centre pile is hero
- Overlays: one primary at a time (deal → trade → play → rankings)

## Copy rules

- "Presidents & Assholes" in player-facing text (brand)
- NZ timestamps in What's New
- Don't promise fixes in Known Issues until shipped

## Mission Control UI

- Desktop-first operational dashboard
- Status colours: green `#22c55e`, amber `#eab308`, red `#ef4444`
- Monospace for gate IDs, build SHA, ISO timestamps
