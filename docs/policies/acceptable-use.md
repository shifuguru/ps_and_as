# Acceptable use policy

Applies to maintainers, contributors with production access, and anyone using privileged tooling against Ps & As systems.

## Allowed

- Developing, testing, and operating the game for players
- Security research reported through [SECURITY.md](../../SECURITY.md)
- Accessing `player-stats` only to fulfill verified support/deletion requests or fix corruption

## Not allowed

- Using production player data for marketing lists or resale
- Sharing production secrets in public channels or committing them to git
- Impersonating players (forging Google sessions, stealing seats) except in documented security tests against non-production or with explicit maintainer approval
- Running destructive commands against production data without a backup and a ticket/reason
- Mining or scraping other players’ identifiers for off-platform use

## Contributors without production access

May run local servers and tests only. Do not ask maintainers to paste production secrets into issues or PRs.

## Enforcement

Violations may result in revoked access and, for severe abuse, legal action. Player-facing terms are described in the [privacy policy](https://shifuguru.github.io/ps_and_as/privacy.html).
